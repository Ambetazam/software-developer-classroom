##Criterios de Aceptación:

    1. Sintaxis Java: Uso correcto de la clase Scanner para lectura de datos y declaración de variables con nombres significativos (Clean Code).
    2. Estructuras de Control: Implementación perfecta del ciclo for (inicialización, condición atada al límite del lote, incremento). Uso de else if con operadores relacionales lógicos (&& si es necesario para los rangos).
    3. Precisión Matemática: Cálculo del promedio aislando el acumulador total y dividiéndolo por el límite del lote, asegurando el uso de números decimales.
